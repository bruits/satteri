Added a WASI-free `@bruits/satteri-wasm` package for browsers and single-threaded edge runtimes such as Cloudflare Workers. It exposes Markdown-to-HTML and MDX-to-HAST bindings backed by the same Rust parser used by Sätteri's native package.
